## Frame pipeline

`net::Driver` sits where `Update` was in the main schedule: offline it runs `Update` once (the pipeline below);
in a LAN session it runs `StateTransition` + `Update` once per lockstep tick, with `DeviceIntents` set to the two
players' `Device::Net` intents and a fixed `dt` (`net::collect` in PreUpdate gathers this machine's input).

```
PreUpdate   input::gather ──▶ DeviceIntents [(Device, Intent)]
                │
Update          ├─ title / pause / results / game-over menus read DeviceIntents (via Session slots)
                │
                ├─ stage: watch_controllers ─▶ pause_when_away ─▶ toggle_pause ─▶ advance_phase (Intro→Play, Won/Lost→next Screen)
                │
                └─ Sim (only: Screen::Stage, !Paused, phase != Intro), chained:
                   spawn_enemies ─▶ versus::spawn_npcs ─▶ tick_timers ─▶ [city: scroll ─▶ wake ─▶ reinforce ─▶ watch ─▶ cull] ─▶ borrow_life ─▶ versus::respawn ─▶ player_control ─▶ enemy::think ─▶ boss::act ─▶ drive ─▶ fire
                   ─▶ fly_bullets ──Hit──▶ resolve_hits ─▶ powerup::pickup ─▶ check_end      (all write Feat ──▶ achieve::track)
                         │  │                    │
                         │  └── Terrain.dirty ───┼──────────────▶ gfx::world::sync_terrain (spawn/despawn chips)
                         └──── Fx / Sfx / Rumble ┘──────────────▶ gfx::fx (particles, shake)   audio::play, music::switch/mix, input::rumble (PostUpdate)
                after(Sim): gfx::world attach_* (Added<T>) + tank_looks/shield_rings/... ; ui::hud::refresh

Leaving Stage (classic): scores::log_stage ──▶ Session.log (StageLog per stage: time, kills, power-ups per player)
Board: ui::board name entry ──▶ scores::Online::send (worker thread: Platform::post_score = curl) ──▶ scores::poll ──▶ ui::board::show
Achievements: Feat ──▶ achieve::track (Tracker -> Record) ; off the stage: achieve::mirror ──▶ achievements.txt, Platform::achieve
              (worker thread), cloud::Pull.want after an unlock
HiScores: Pick (selectors) ──▶ ui::hiscores::fetch (worker thread: Platform::fetch_board = curl GET ?format=text) ──▶ parse_board ──▶ refresh
```

## State machine

```
Achievements ◀──ACHIEVEMENTS / B──▶ Title (hosts with Platform::achieve) ◀──B── Bunker ◀──title COMBO (offline)
GameOver / district Results ──A──▶ [Unlocks (new achievements, not in LAN)] ──A──▶ [Board] ──▶ Title / CityMap
HiScores ◀──HI SCORES / B──▶ Title ◀──B / linked──▶ Lan (LAN CO-OP)
Settings ◀──SETTINGS / B──▶ Title ──PLAY──▶ Play ──CLASSIC──▶ StageSelect ──A──▶ Stage ──all 20 killed──▶ Results ──tally, then A / 10 s──▶ Stage (n+1)
                             ▲                │
                             │                └──base destroyed or everyone out──▶ GameOver ──A──▶ [Board ──A / B──▶] Title
                             └────────────── pause menu "QUIT TO TITLE" ◀──────────┘
```

`[Board]` = the world board screen, only when it is on (game key + host `post_score`) and the run counts.

VERSUS: Title ──PLAY──▶ Play ──VERSUS (2 joined, offline)──▶ Stage (mode Versus, map n) ──a base falls or a player is
out──▶ VersusResults ──A──▶ Stage (next map) / ──B──▶ Title.

City Run: Title ──PLAY──▶ Play ──CITY RUN──▶ CityMap ──A──▶ Stage (mode City) ──boss killed──▶ Results ──▶ [Board ──▶] CityMap;
game over ──▶ CityMap (retry). B on the map or the stage tiles ──▶ Play ──B──▶ Title.

`StageRun.phase` inside `Screen::Stage`: `Intro` (banner, frozen) → `Play` → `Won` | `Lost` (3 s, world keeps
running) → next screen. `Paused` is a separate resource; the pause overlay is part of the stage UI.
