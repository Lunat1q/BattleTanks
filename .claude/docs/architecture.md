# Architecture

## Source tree

```
build.rs              # wraps assets/icon.ico into a Win32 .res and passes it to the MSVC linker (exe icon);
                      # bakes the gitignored scores.key in as BT_SCORES_KEY (world board game key; none = offline build)
docs/steam/*.png      # Steam library art (capsules, hero, logo, icon) from `cargo test write_steam_art -- --ignored`; committed
assets/music/*.ogg    # owner-made music, Vorbis q1, baked in by music.rs (ADR 0007; MP3 masters gitignored)
assets/icon.ico|png   # generated by `cargo test write_icon_file -- --ignored`; committed
Cargo.toml            # bevy 0.20 (2d, ui, bevy_audio, wav, png); dev deps opt-level 3; release thin LTO + strip
levels/NN.txt         # 30 stage maps, baked into the exe with include_str! (format in levels.rs)
levels/city/NN.txt    # 10 City Run districts, 15-24 screens tall (format in city_map.rs), drawn by city_gen
src/
  main.rs             # Windows exe: calls battle_tanks::run()
  lib.rs              # run() / run_with(Platform, extra plugins): loads Settings first so the window opens in the saved mode;
                      # plugin list. Public API for wrapper crates: Platform (incl. post_score, fetch_board), TvRemote, canvas, paint_icon, paint_banner
  geom.rs             # units (SUB 4, CELL 8, TILE 16, FIELD 208), Dir, rect overlap, grid snap  [pure]
  rng.rs              # xorshift64* Resource: below/range/chance/pick/shuffle                     [pure]
  scores.rs           # Best (hi score + last initials) <-> scores.txt; world board: payload (stage log JSON), city_payload
                      # (district clear time + kills), curl_post, Online (worker thread -> poll), parse_board (plain-text
                      # answer), curl_get (HI SCORES); log_stage on leaving a stage or district; CITY_FACTS test = server table  [ADR 0009, 0010]
  settings.rs         # Settings (fps, vsync, fullscreen, volume, music, shake, show_fps, friendly_fire, vibration) <-> %APPDATA%\BattleTanks\settings.txt;
                      # apply to window, F11 toggle, FPS overlay, frame limiter in Last
  rules.rs            # every gameplay number: speeds, timers, enemy stats, gun levels, scoring    [pure]
  terrain.rs          # 52-wide sub-cell grid, any height; tank blocking, bullet impact strip, Wall/Gate/Secret, base ring, dirty list [pure]
  levels.rs           # parse stage files, force spawns/base clear, rosters, harder laps         [pure]
  city_map.rs         # parse district files: tall terrain, placed enemies/turrets/minis/boss, gates, stashes [pure]
  city_gen.rs         # test-only: write_city_districts draws levels/city/*.txt from each district's plan (height, turrets,
                      # minis, enemies) in bands bottom-up, redrawing any band that leaves no tank-sized way up
  city_brushes/       # test-only street brushes per district theme (picked by name): mod.rs helpers, outer.rs 1-5, inner.rs 6-10
  input.rs            # Device (pads, two keyboard layouts) -> Intent per frame (DeviceIntents); Rumble -> pad; TvRemote marker
  audio.rs            # synthesises WAVs at startup; plays Sfx messages (deduped per frame); BT_SHOT/BT_MUTE mute
  music.rs            # one track at a time: pick(screen, mode, stage, boss up) -> pool, next() on end [pure]; pauses with the game
  dev.rs              # BT_SHOT smoke hook: auto-join, start stage, screenshot, log average fps, quit
  game/
    mod.rs            # Screen state, Mode, Session/Slot, StageRun, View, components, Fx/Sfx messages, Sim schedule
    stage.rs          # OnEnter build (classic or city), spawn_enemy, respawn point, timers, borrow a tank, win/lose, pause (+ app in background), pad loss
    city.rs           # City Run: scroll the View, wake placed enemies, reinforcements, turret->gate, reveal secrets, cull, Progress save
    tank.rs           # player_control (intent -> want/trigger), drive (collisions, snap, ice), fire
    enemy.rs          # think: choose_dir (pure) + random fire, freeze; turrets aim at the nearest player
    combat.rs         # fly_bullets (sub-steps: tanks, base, terrain; bullet-vs-bullet) -> Hit; resolve_hits
    powerup.rs        # drop on bonus hit, pickup effects
  gfx/
    mod.rs            # Gfx handles (built at plugin time), colours, z layers, camera (FixedVertical 224) + bloom
    canvas.rs         # SDF painter -> Image; sd_box/rbox/circle/seg/poly, star, tileable noise   [pure]
    art_tanks.rs      # 4 player + 4 enemy tank models x 2 tread frames, mini-boss, boss, turret; grey (tinted by Sprite.color)
    art_world.rs      # brick, steel, water x3, trees, ice, ground, base (alive/destroyed)
    art_icons.rs      # bullet, particle dot, spawn sparkle, shield ring, flag, 6 power-up icons
    world.rs          # terrain sub-cell sprites from the dirty list, water anim, attach/update tank/bullet/base/power-up sprites
    icon.rs           # app icon painter; runtime window/taskbar icon (winit); ICO writer (test-only)
    art_promo.rs      # title banner (pub: paint_banner, used by the Android wrapper); Steam capsules/hero/logo (test-only writer)
    fx.rs             # Fx messages -> particles, score pop-ups (Text2d), camera shake
  ui/
    mod.rs            # text() in vh units, colours, menu helpers
    title.rs          # join/leave slots, START / STAGE <n> / CITY RUN / HI SCORES / SETTINGS / EXIT
    city_map.rs       # district map: 10 dots + dotted roads, pick an unlocked district
    settings.rs       # rows from settings::ITEMS + BACK; saves on every change
    hud.rs            # side panels: lives, score, power, enemy reserve icons (City Run: district track), stage flag
    screens.rs        # stage banner, pause menu (+ pad-lost note), results and game over screens
    tally.rs          # results / game over table; classic count-up (tally_view pure: rows, blips, time bonus, score)
    board.rs          # Screen::Board after game over (classic) / district results (City): 7-letter name entry per player
                      # (prefilled), A send / B skip, world rank + top 3 + 2 above / 1 below
    hiscores.rs       # Screen::HiScores from the title: MODE / PLAYERS / DISTRICT selectors (Pick -> board id), top 10 per
                      # board fetched once per visit on a worker thread (Platform::fetch_board), colour-coded rows
```

## Frame pipeline

```
PreUpdate   input::gather ──▶ DeviceIntents [(Device, Intent)]
                │
Update          ├─ title / pause / results / game-over menus read DeviceIntents (via Session slots)
                │
                ├─ stage: watch_controllers ─▶ pause_when_away ─▶ toggle_pause ─▶ advance_phase (Intro→Play, Won/Lost→next Screen)
                │
                └─ Sim (only: Screen::Stage, !Paused, phase != Intro), chained:
                   spawn_enemies ─▶ tick_timers ─▶ [city: scroll ─▶ wake ─▶ reinforce ─▶ watch ─▶ cull] ─▶ borrow_life ─▶ player_control ─▶ enemy::think ─▶ drive ─▶ fire
                   ─▶ fly_bullets ──Hit──▶ resolve_hits ─▶ powerup::pickup ─▶ check_end
                         │  │                    │
                         │  └── Terrain.dirty ───┼──────────────▶ gfx::world::sync_terrain (spawn/despawn chips)
                         └──── Fx / Sfx / Rumble ┘──────────────▶ gfx::fx (particles, shake)   audio::play, music::switch/mix, input::rumble (PostUpdate)
                after(Sim): gfx::world attach_* (Added<T>) + tank_looks/shield_rings/... ; ui::hud::refresh

Leaving Stage (classic): scores::log_stage ──▶ Session.log (StageLog per stage: time, kills, power-ups per player)
Board: ui::board name entry ──▶ scores::Online::send (worker thread: Platform::post_score = curl) ──▶ scores::poll ──▶ ui::board::show
HiScores: Pick (selectors) ──▶ ui::hiscores::fetch (worker thread: Platform::fetch_board = curl GET ?format=text) ──▶ parse_board ──▶ refresh
```

## State machine

```
HiScores ◀──HI SCORES / B──▶ Title
Settings ◀──SETTINGS / B──▶ Title ──START──▶ Stage ──all 20 killed──▶ Results ──tally, then A / 10 s──▶ Stage (n+1)
                             ▲                │
                             │                └──base destroyed or everyone out──▶ GameOver ──A──▶ [Board ──A / B──▶] Title
                             └────────────── pause menu "QUIT TO TITLE" ◀──────────┘
```

`[Board]` = the world board screen, only when it is on (game key + host `post_score`) and the run counts.

City Run: Title ──CITY RUN──▶ CityMap ──A──▶ Stage (mode City) ──boss killed──▶ Results ──▶ [Board ──▶] CityMap;
game over ──▶ CityMap (retry). B on the map ──▶ Title.

`StageRun.phase` inside `Screen::Stage`: `Intro` (banner, frozen) → `Play` → `Won` | `Lost` (3 s, world keeps
running) → next screen. `Paused` is a separate resource; the pause overlay is part of the stage UI.
